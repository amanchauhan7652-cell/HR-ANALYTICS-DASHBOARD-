HR Analytics Dashboard 

 Project Overview

This project focuses on HR Analytics to analyze employee data and generate meaningful business insights using Microsoft Excel.

Objectives-

- Analyze employee information.
- Understand employee distribution.
- Track employee performance.
- Identify important HR trends.
- Support data-driven decision-making.

Tools & Technologies-

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Charts & Visualization

Dashboard-

The dashboard provides a visual representation of HR data to help understand important employee-related insights.

Key Learnings-

- Data cleaning and preprocessing.
- Data visualization.
- Creating interactive reports.
- Analyzing business data.
